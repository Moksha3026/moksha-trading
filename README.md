# Moksha Trading

Marketing site for Moksha Trading — garment sourcing, printing and export, Ahmedabad, Gujarat.

Built with Next.js (App Router, TypeScript).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Deploy

Deploys cleanly to [Vercel](https://vercel.com) with zero configuration: push to a GitHub repo, import it in Vercel, done.

## Notes

- Product/section photos in `public/images/` are stock photos from [Pexels](https://www.pexels.com) (free for commercial use under the [Pexels License](https://www.pexels.com/license/)). Swap them for real product/facility photos when available.
- The enquiry form opens a pre-filled `mailto:` draft — no backend required.
